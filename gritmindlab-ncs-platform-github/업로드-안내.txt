그릿마인드랩 NCS 플랫폼 · GitHub Pages 업로드 안내

1. GitHub에서 사용할 저장소를 엽니다.
2. Add file → Upload files를 누릅니다.
3. 이 폴더 안의 파일과 폴더를 모두 업로드합니다.
   중요: 바깥쪽 폴더가 아니라 index.html, assets, cbt, calendar, admin이
   저장소 첫 화면에 바로 보여야 합니다.
4. Commit changes를 누릅니다.
5. Settings → Pages로 이동합니다.
6. Source에서 Deploy from a branch를 선택합니다.
7. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
8. 잠시 후 Pages 화면에 표시되는 주소로 접속합니다.

구성
- index.html: 통합 홈페이지
- cbt/: 학생용 NCS CBT
- calendar/: 공기업 채용달력
- admin/: 이메일 로그인 방식 관리자·문제은행
- assets/: 통합 디자인과 공유 이미지

주의
- Firebase 설정과 관리자 보안 규칙은 기존 프로젝트 설정을 그대로 사용합니다.
- 관리자 이메일과 비밀번호를 GitHub 파일에 추가하지 마세요.
